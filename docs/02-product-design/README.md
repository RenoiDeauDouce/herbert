# 02 – Product design

**Statut** : à écrire. Le plan ci-dessous est provisoire, à valider pendant le brainstorming.

**Rôle** : décrire ce que voit et fait le designer, et les règles que l'interface respecte.

**Dépend de** : 01 (le périmètre d'`alpha.1`).

**Source visuelle** : la maquette Figma (fondations, composants, trois écrans).

## Sections prévues

1. Parcours et états d'une session : ouverture, les quatre étapes, la décision, l'attestation.
2. Règles par composant : chips, rail, critères, option, décision, échelle `attest`, récit, bandeau dégradé, validation d'écriture.
3. Contenus : microcopie, « À renseigner », ton.
4. Accessibilité : taille minimale du texte courant, contrastes, états sans couleur seule.
5. `alpha.1` (conversation) et suite (panneau) : ce qui est dedans, ce qui va au registre (C-08 à C-10).
