# Registre des changements

Pendant le gel, chaque envie de modification est consignée ici, jamais appliquée. Une entrée, un fichier : `C-XX-titre-court.md`.

## Champs d'une entrée

| Champ | Contenu |
| --- | --- |
| ID | C-01, C-02… |
| Problème observé | Ce qui s'est passé, avec l'identifiant de la session concernée, ou « Sans objet (avant le gel) » |
| Changement proposé | La règle, le skill, le seuil ou le schéma touché |
| Classe | Un seul KPI, plusieurs KPI, ou contrat public |
| KPI touché | K-01 à K-12 |
| Signal attendu | Ce qui doit bouger si le changement fonctionne |
| Seuil d'anomalie | Fixé avant la semaine de réintroduction, jamais après |
| Rang | Ordre de réintroduction proposé |
| Statut | En attente, réintroduit, retiré ou reporté |

## État

Les dix entrées actuelles (C-01 à C-10) sont dans le registre en ligne, lié depuis le [README racine](../../README.md). Elles seront reprises ici une à une.

Le registre ne contient aucun texte de décision ni donnée personnelle (G-07).
